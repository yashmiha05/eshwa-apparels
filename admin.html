Admin Login

Paste your GitHub Personal Access Token to unlock product management. This stays only in your browser — it's never sent anywhere except directly to GitHub.

Don't have one? See the "How to get a token" guide below.

How to get a token (one-time, 2 minutes)

1. Go to github.com/settings/tokens/new

2. Note: "Eshwa Admin"  •  Expiration: 90 days (or No expiration)

3. Under "Select scopes", tick the box next to repo

4. Scroll down, click Generate token

5. Copy the token (starts with ghp_) and paste it above. GitHub only shows it once — if you lose it, just generate a new one.
